# Recordly 项目介绍文档

> GitHub仓库地址：https://github.com/webadderallorg/Recordly
> 开源协议：**AGPL‑3.0**

## 一、Recordly 是做什么的

Recordly 是一款**跨平台开源桌面录屏+视频编辑器**，专门用于快速制作高质量产品演示、操作教程、软件演示、讲解类视频。

传统录屏工具只能输出原始录像，想要做放大聚焦、美化光标、美化背景、摄像头画中画，录完还需要导入剪映等第三方剪辑软件二次加工。
而 Recordly 将**录制、动效美化、剪辑、导出**全部集成在同一个软件内，录完即可完成大部分后期，几分钟就能产出精致演示视频，对标商业工具 Screen Studio，并且完全免费开源。

支持系统：
- macOS 14.0+（使用系统 ScreenCaptureKit 原生捕获）
- Windows10 20H1(Build 19041)+（WGC原生捕获、WASAPI系统音频）
- Linux现代发行版（Electron捕获，暂不支持隐藏原生光标）

## 二、如何使用｜核心功能

整体工作流程：**录制屏幕 → 内置时间轴编辑美化 → 直接导出视频/GIF**，工程文件保存为 `.recordly`，可以反复打开继续编辑。

### 1️⃣ 录制功能
1. 支持录制**整个显示器 / 单个应用窗口**
2. 同时捕获麦克风音频 + 系统内部音频
3. 录制结束直接跳转编辑器，也可以打开旧录制文件/工程文件继续编辑

### 2️⃣ 时间轴剪辑（面向演示视频设计）
- 拖拽式时间轴，裁剪片段、分割视频
- **自动缩放建议**：分析光标点击行为自动生成缩放聚焦，也可以手动添加缩放区域，突出操作重点
- 局部变速：给片段设置加速、慢动作
- 添加文字、图片标注；增加额外音频轨道
- 视频画面裁剪，自定义输出画面比例

### 3️⃣ 光标美化（项目一大特色）
不用后期软件，直接渲染美化后的光标：
- 调整光标大小、平滑移动轨迹、运动模糊
- 点击弹跳效果、光标摇摆、循环光标动画
- 提供macOS风格渲染光标素材，录制时可以隐藏系统原生光标，使用美化后的光标替代输出

### 4️⃣ 摄像头气泡叠加
把摄像头画面做成圆角悬浮气泡叠加在录屏画面：
- 自定义大小、位置、镜像、圆角、阴影
- 开启缩放联动：画面放大缩小时摄像头气泡自动适配，保证视觉平衡

### 5️⃣ 画面框架与背景美化
一键美化整体视频外观：
- 内置壁纸、支持自定义图片背景、纯色、渐变背景、背景模糊
- 设置视频圆角、内边距、投影阴影，一键生成精致样机式画面效果
- 多种输出比例预设

### 6️⃣ 扩展插件生态
拥有社区扩展市场，第三方开发者可以开发插件：自定义光标音效、设备外壳模板、壁纸、渲染钩子等，拓展软件能力。

### 7️⃣ 导出输出
- MP4标准视频、GIF动图
- 自定义画质、GIF帧率、GIF循环开关、输出分辨率
- 导出完成直接打开输出目录查看文件

### 8️⃣ 其他
自定义快捷键、多语言支持（含简体中文）；支持源码编译，也可以直接下载预编译安装包使用。

## 三、核心优点

1. **一站式完整工作流，效率高**
录屏、剪辑、光标美化、背景样式、摄像头叠加全部在一个软件完成，**无需导出原始素材再导入第三方剪辑软件**，快速产出演示视频，适合产品演示、教程录制。

2. **真正开源免费，可二次开发**
AGPL‑3.0开源协议，无付费订阅、无水印；开发者可以阅读源码，修改、编译自己的版本，支持社区提交PR贡献代码。

3. **系统原生捕获，录制质量优秀**
macOS、Windows优先调用操作系统原生录屏接口，不是单纯Electron截图，录制清晰度、音频捕获效果优于很多纯Electron录屏工具；Linux兼容支持。

4. **预览渲染和导出渲染同源，所见即所得**
使用PixiJS GPU渲染引擎，编辑器预览画面和最终导出视频使用同一套渲染逻辑，**避免预览和导出成品效果不一致的问题**。

5. **强大的演示向专属动效**
自动智能缩放、全套光标动画、动态摄像头气泡，这些大多是商业付费录屏软件才有的能力，Recordly免费提供。

6. **工程文件保存，可持续迭代**
`.recordly`工程文件保存全部编辑状态，随时可以二次修改，不用重新录屏。

7. **插件扩展生态**
社区插件市场，可不断拓展能力，适配更多创作者需求。

## 四、已知局限（客观说明）
1. Linux平台无法隐藏系统原生光标，开启渲染光标时，导出视频可能同时出现两个光标。
2. Windows低于19041旧版本会降级捕获，原生光标无法隐藏。
3. macOS要求最低版本14.0，旧macOS版本无法使用完整原生捕获能力。

## 五、获取方式
1. 下载预编译包：GitHub Releases页面下载各系统安装包
2. Arch/Manjaro：`yay -S recordly‑bin`
3. 源码编译：克隆仓库执行`npm install && npm run build`编译本地安装包。
